<h2>📦 ¿Qué es ForjaStyle?</h2>
<p>
  <strong>ForjaStyle</strong> no es un simple archivo .CSS; es tu <strong>mesa de trabajo</strong> para el frontend. Es una librería de diseño inspirada en la robustez de la piedra y la elegancia del diamante, ofreciendo componentes modulares listos para ser equipados en cualquier bioma web.
</p>

<h2>🛠️ Características del Crafteo</h2>
<ul>
  <li>🟩 <strong>Bioma Visual:</strong> Estetica basada en Minecraf</li>
  <li>⚔️ <strong>Equipo de Combate:</strong> Componentes de alto nivel: botones reforzados, tarjetas de inventario, alertas de creeper y más.</li>
  <li>🏃 <strong>Movilidad (Responsive):</strong> Tu web correrá tan fluido como un sprint, adaptándose a cualquier tamaño de pantalla (Mobile First).</li>
  <li>⚙️ <strong>Arquitectura Modular:</strong> Construido con SASS, separando variables, mixins y utilidades para que no se te llene el inventario de código basura.</li>
  <li>💎 <strong>Design Tokens:</strong> Sistema inteligente de variables que cambian el tema del mundo con un solo comando.</li>
</ul>
