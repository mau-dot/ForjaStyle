Implementación vía CDN

La forma más sencilla de comenzar. Solo copia y pega el siguiente enlace en la cabecera de tu archivo HTML.

HTML 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/mau-dot/ForjaStyle@main/css/main.css">

Nota: Coloca el link siempre dentro del <head> de tu documento.

Accesibilidad y Estilo

ForjaStyle ha sido creada con principios de accesibilidad para asegurar una estructura clara, herramientas semánticas y una combinación de colores con contraste suficiente que mejora la experiencia visual de cualquier usuario.

🗄️

Sintaxis Lógica

Clases predecibles y fáciles de recordar para un desarrollo fluido y rápido.

👁️

Alto Contraste

Combinaciones de colores que favorecen la legibilidad en cualquier tipo de pantalla.

📱

Diseño Adaptable

Adaptabilidad garantizada en móviles, tablets y escritorios mediante nuestro sistema de grid.

✨

Efectos Sutiles

Evitamos el uso excesivo de animaciones, priorizando efectos visuales suaves y profesionales.
