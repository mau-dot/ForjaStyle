Aqui te mostramos como instalar nuestra libreria!

Implementación vía CDN

La forma más sencilla de comenzar. Solo copia y pega el siguiente enlace en la cabecera de tu archivo HTML.

HTML 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/mau-dot/ForjaStyle@main/css/main.css">
Ejemplo de cómo debe verse en tu código:

Nota: Coloca el link siempre dentro del <head> de tu documento.

Descarga Local

Si prefieres trabajar de forma local sin depender de una conexión externa, descarga el archivo compilado. Y solo lo agregas a tu proyecto y LISTO ya puedes utilizar nuestra libreria!
