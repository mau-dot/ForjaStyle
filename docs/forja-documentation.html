¿QUÉ ES FORJASTYLE?

FORJASTYLE es un sistema de diseño artesanal. No nació para ser el framework más grande del mundo, sino para ser el más preciso. Construido para quienes disfrutan de ensuciarnos las manos con el código, buscando una base sólida, limpia y estética.

  • Diseño con Alma: Un minimalismo funcional donde la paleta de colores guía al usuario sin esfuerzo visual.
  • Control Total: Basado en arquitectura SASS 7-1 para que tú mandes sobre el diseño, no el framework sobre ti.
  • Ligero: Sin dependencias pesadas, optimizado para una carga rápida y compilación inmediata.

LAYOUT

Grid Layout y Container La Base de Forja Style

Grid System

El sistema de rejilla de ForjaStyle se basa en un esquema de 12 columnas flexibles utilizando Flexbox. Permite crear estructuras complejas y adaptables a cualquier dispositivo.

Lógica de Columnas

Utilizamos la siguiente sintaxis de concatenación: clase-pantalla-número. El contenedor principal siempre debe llevar la clase .row.

  • Contenedor: .row (Activa el contexto Flexbox).
  • Columnas: .col- seguido del número (1 al 12).
  • Breakpoints: -md-, -lg- para definir anchos en diferentes pantallas.

Visualización de anchos comunes:

col-12 (100%)
col-6 (50%)
col-6 (50%)
col-4
col-4
col-4
HTML 
<!-- Estructura básica de 3 columnas -->
                  <div class="row">
                  <div class="col-md-4"> Columna 1 </div>
                  <div class="col-md-4"> Columna 2 </div>
                  <div class="col-md-4"> Columna 3 </div>
                  </div>

Nota: En ForjaStyle, el gutter (espacio entre columnas) se controla con la clase g- seguida del número de escala (ej. g-2), permitiendo una separación limpia y artesanal.

Los contenedores son el elemento de diseño fundamental en ForjaStyle. Envuelven, rellenan y centran el contenido de tu página de manera responsiva.

Bordes (Borders)

Las utilidades de bordes te permiten añadir o quitar contornos, cambiar su color y modificar el radio de las esquinas (border-radius) de forma rápida y sin tocar el CSS.

Nomenclatura de Clases

  • .border: Añade un borde sólido base (generalmente 1px gris).
  • .border-0: Elimina todos los bordes de un elemento.
  • .border-{color}: Aplica el color del tema (ej. .border-primary, .border-danger).
  • .rounded-{tamaño}: Modifica el radio de las esquinas. Usa -sm (pequeño), -lg (grande), -pill (píldora), o -0 (cuadrado perfecto). La clase .rounded por sí sola aplica el tamaño medio.

Colores (Colors)

Lo más importante al crear un diseño es la elección de colores. Hemos forjado una paleta minimalista que se adapta automáticamente al Modo Claro y Modo Oscuro para garantizar la mejor legibilidad según las preferencias del usuario.

Nomenclatura de Clases

En lugar de escribir variables CSS a mano, utiliza nuestras clases utilitarias de prefijo para aplicar color rápidamente:

  • .bg-{color}: Aplica el color como fondo (ej. .bg-primary, .bg-danger).
  • .text-{color}: Aplica el color al texto (ej. .text-success, .text-muted).

Display (Visualización)

Alterna rápida y eficientemente el valor de la propiedad display de tus elementos. Estas clases incluyen soporte completo para diseño responsivo, permitiendo mostrar u ocultar elementos según el dispositivo del usuario.

Nomenclatura de Clases

  • .d-{valor}: Aplica la propiedad desde pantallas móviles hacia arriba (ej. .d-none, .d-block, .d-inline-block, .d-flex).
  • .d-{breakpoint}-{valor}: Aplica la propiedad solo a partir del tamaño de pantalla indicado (ej. .d-md-none, .d-lg-block).

Comportamiento Base

.d-inline-block
.d-inline-block

Los elementos inline-block se colocan uno al lado del otro y respetan el padding y margin.

.d-block

Un elemento block ocupará todo el ancho disponible por defecto, empujando otros elementos hacia abajo.

Efectos y Sombras (Effects)

Añade profundidad, interactividad y fluidez a tus elementos con nuestras utilidades de sombras, estados de cursor y efectos de transformación al pasar el mouse.

Flexbox (Alineación y Distribución)

Controla rápidamente la dirección, justificación, alineación y el espaciado de tus elementos utilizando el poder de Flexbox sin necesidad de escribir CSS adicional. Nuestras utilidades cubren el 100% de las necesidades de maquetación moderna.

Nomenclatura de Clases Básicas

Todo comienza aplicando .d-flex o .d-inline-flex al contenedor padre. A partir de ahí, puedes usar todo este arsenal:

  • Dirección: .flex-row, .flex-row-reverse, .flex-column, .flex-column-reverse.
  • Envoltura (Wrap): .flex-wrap, .flex-nowrap, .flex-wrap-reverse.
  • Eje Principal (Justify): .justify-content-{start|end|center|between|around|evenly}.
  • Eje Cruzado (Align Items): .align-items-{start|end|center|baseline|stretch}.
  • Hijos Individuales (Align Self): .align-self-{start|end|center|baseline|stretch}.
  • Comportamiento (Grow/Shrink): .flex-grow-0, .flex-grow-1, .flex-shrink-0, .flex-shrink-1, .flex-basis-auto.
  • Ordenamiento: .order-first, .order-last, .order-0 al .order-5.
  • Separación (Gap): .gap, o escalado desde .gap-0 hasta .gap-10.

Variantes Responsivas

Casi todas las clases anteriores tienen variantes para cada tamaño de pantalla (sm, md, lg, xl). La fórmula es insertar el breakpoint justo después del prefijo de la clase:

  • Direccion: .flex-{breakpoint}-row (Ej: .flex-md-column)
  • Alineación: .justify-content-{breakpoint}-center (Ej: .justify-content-lg-between)
  • Wrap: .flex-{breakpoint}-wrap (Ej: .flex-sm-nowrap)
  • Orden: .order-{breakpoint}-2 (Ej: .order-xl-last)

Tipografía

En ForjaStyle sabemos la importancia de la accesibilidad a la hora de definir tamaños a las fuentes
Por eso nos hemos encargado de definir una jerarquía visual clara utilizando escalas rem para accesibilidad.

Tambien definiendo tipografias como sans serif para una mejor comprension, comodidad visual, y minimalismo

Los tamaños son los siguientes:

  • fs-1 = 2.5rem
  • fs-2 = 2rem
  • fs-3 = 1.75rem
  • fs-4 = 1.50rem
  • fs-5 = 1.25rem
  • fs-6 = 1

Los weight son los siguientes:

  • fw-light = 300
  • fw-normal = 400
  • fw-medium = 500
  • fw-bold = 700

Los estilos son los siguientes:

  • font-primary = Arial
  • font-fallback = Sans Serif
  • font-family-base = $font-primary, $font-fallback

la sintaxis correcta es:

text = clase principal "-" usamos guion para concatenarlo al estilo

la fuente base es Arial para el sistema

La manera de declararlo es la siguiente:

class = "text-primary fs-5" //Texto con estilo primario, y tamaño de fuente de 1.25 rem

HTML 
<div>
    <span class="fs-1 fw-ligth text-muted">Hola mundo</span>
</div>

fs-1: Título Principal

fs-2: Subtítulo de Sección

fs-3: Encabezado de Componente

fs-5: Este es el cuerpo de texto estándar para una lectura fluida.
