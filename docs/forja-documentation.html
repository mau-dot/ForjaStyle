¿QUÉ ES FORJASTYLE?

FORJASTYLE es un sistema de diseño artesanal. No nació para ser el framework más grande del mundo, sino para ser el más preciso. Construido para quienes disfrutan de ensuciarnos las manos con el código, buscando una base sólida, limpia y estética.

  • Diseño con Alma: Un minimalismo funcional donde la paleta de colores guía al usuario sin esfuerzo visual.
  • Control Total: Basado en arquitectura SASS 7-1 para que tú mandes sobre el diseño, no el framework sobre ti.
  • Ligero: Sin dependencias pesadas, optimizado para una carga rápida y compilación inmediata.

Grid System

El sistema de rejilla de ForjaStyle se basa en un esquema de 12 columnas flexibles utilizando Flexbox. Permite crear estructuras complejas y adaptables a cualquier dispositivo.

Lógica de Columnas

Utilizamos la siguiente sintaxis de concatenación: clase-pantalla-número. El contenedor principal siempre debe llevar la clase .row.

  • Contenedor: .row (Activa el contexto Flexbox).
  • Columnas: .col- seguido del número (1 al 12).
  • Breakpoints: -md-, -lg- para definir anchos en diferentes pantallas.

Visualización de anchos comunes:

col-12 (100%)
col-6 (50%)
col-6 (50%)
col-4
col-4
col-4
HTML 
<!-- Estructura básica de 3 columnas -->
<div class="row">
  <div class="col-md-4"> Columna 1 </div>
  <div class="col-md-4"> Columna 2 </div>
  <div class="col-md-4"> Columna 3 </div>
</div>

Nota: En ForjaStyle, el gutter (espacio entre columnas) se controla con la clase g- seguida del número de escala (ej. g-2), permitiendo una separación limpia y artesanal.

Tipografía

En ForjaStyle sabemos la importancia de la accesibilidad a la hora de definir tamaños a las fuentes
Por eso nos hemos encargado de definir una jerarquía visual clara utilizando escalas rem para accesibilidad.

Tambien definiendo tipografias como sans serif para una mejor comprension, comodidad visual, y minimalismo

Los tamaños son los siguientes:

  • fs-1 = 2.5rem
  • fs-2 = 2rem
  • fs-3 = 1.75rem
  • fs-4 = 1.50rem
  • fs-5 = 1.25rem
  • fs-6 = 1

Los weight son los siguientes:

  • fw-light = 300
  • fw-normal = 400
  • fw-medium = 500
  • fw-bold = 700

Los estilos son los siguientes:

  • font-primary = Arial
  • font-fallback = Sans Serif
  • font-family-base = $font-primary, $font-fallback

la sintaxis correcta es:

text = clase principal "-" usamos guion para concatenarlo al estilo

la fuente base es Arial para el sistema

La manera de declararlo es la siguiente:

class = "text-primary fs-5" //Texto con estilo primario, y tamaño de fuente de 1.25 rem

HTML 
<div>
    <span class="fs-1 fw-ligth text-muted">Hola mundo</span>
</div>

fs-1: Título Principal

fs-2: Subtítulo de Sección

fs-3: Encabezado de Componente

fs-5: Este es el cuerpo de texto estándar para una lectura fluida.

Botones

Los botones son parte escencial de cada sitio web, nos indican las acciones que queremos realizar
Creando un buen y llamativo diseño logramos que pase de ser un contenedor plano a algo que se ajusta bien a cada proyecto

Contamos con los siguientes tipos de botones

  • Boton Primario: ideal para cualquier tipo de acción
  • Boton Outline Info: ideal para tarjetas, especialmente para apartados de mostrar más
  • Boton exitoso: te haces exitoso al tocarlo, ideal para menus de eleccion entre una acción positiva o negativa
  • Boton Danger: peligro, Boton diseñado especialmente en el enfoque de la cancelacion de una acción
La sintaxis correcta para usarlo debe ser en el contenedor que quieras usar
Preferiblemente usarlos en contenedores Button.
Se declara
<button class = "btn// clase global para botones(btn) btn-primary //diseño del boton">

La sintaxis para utilzarlo es la siguiente

HTML 
<div>
    <button class "btn btn-primary shadow-sm hover-lift">Ingresar</Button>
</div>

Paleta de Colores

Lo mas importante al crear un diseño es la elección de colores
hemos tomado una paleta de colores minimalista, se ha ideado un modo claro y modo oscuro, para una mejor legibilidad y diseño en base a las preferencias del usuario.

Contamos con modo oscuro y modo claro para el sistema

Primary: --primary
Accent Gold: --accent
Muted Purple: --text-muted

el sistema de cambio de colores se encuentra integrado en los componentes, de igual manera cuentas con la libertad de hacer uso personalizado de ellos

HTML 
<div>
    <span style="background-color: var(--background)">Ingresar</span> //se aplicara el color de fondo
</div>

Alertas y Badges

implementamos badges y alertas con diseño responsivo para que el usuario tenga informacion de sus acciones, como inicios de sesion, credenciales erroneas, datos erroneos

La manera de utilizarlas son las siguientes:

Badges

  • class = "badge bg-primary"
  • class = "badge bg-success"
  • class = "badge bg-danger

    • alertas

  • class = "alert alert-success"
  • class = "alert alert-warning"
  • class = "alert alert-info"
Información relevante Ingresado correctamente al sistema Error en las credenciales, vuelva a intentarlo

Las alertas tambien son parte importante de un sitio web y en este apartado mostramos como utilizarlas

Soy una alerta Soy una alerta Soy una alerta

Se implementan de la siguiente manera:

HTML 
<div class="row">
  //uso de alertas
  <span class=" alert alert-success"> Contenido</span>
  <span class=" alert alert-warning"> Contenido</span>
  <span class=" alert alert-info"> Contenido</span>
  //uso de badges
  <span class=" badge bg-primary"> Contenido</span>
  <span class=" badge bg-danger"> Contenido</span>
  <span class=" badge bg-success"> Contenido</span>
</div>
Nota: Alertas y badges sencillas pero llamativas Informan pero no molestan al usuario
